Functional enrichment of genomic regions

GREAT assigns each region to the genes whose regulatory domains it falls in, then tests GO terms, phenotypes and genes with a binomial test over regions and a hypergeometric test over genes (McLean et al. 2010). This server reproduces GREAT 4.0.4, whose original site is offline, and GREAT 3.0.0 for earlier analyses, and answers rGREAT and GREAT's batch API.

GREAT batch interface

GREAT's Programming Interface: a tab-separated table of every ontology (outputType=batch) or a results page (web). Besides requestURL, a file can be posted as requestFile. Add version=3 (or call public-3.0.0/cgi-bin/) for GREAT 3.0.0; the default is 4.0.4. extraOntologies=1 (or public-extra/cgi-bin/) adds the ontologies GREAT 4.0.4 dropped.

Input

BED3 to BED12, narrowPeak / broadPeak, bedGraph, MACS .xls, CSV or TSV tables with a header (chrom/seqnames, start, end in any column), region strings (chr1:100-200, chr1-100-200), .gz/.bz2/.zip. Chromosome names such as 1 or MT are recognized; contigs outside the assembly are skipped and reported.
