Quick guide

Genome Canvas guide

1

Select a reference genome

Choose a common assembly from the top bar, or load a custom FASTA or 2bit reference.

2

Add tracks

Select files directly from configured server directories, pick from the tracks others in the lab have loaded (Shared tracks), or connect public hubs and URLs such as ENCODE and 1000 Genomes.

3

Navigate and explore

Search coordinates, genes, or rsIDs, drag to pan, right-click a track for settings, or enable Highlight and drag across a track to mark an interval.

4

Export and share

Export the current canvas as PNG, save a Favorite profile, or create a LAN-only short link stored on this server.
